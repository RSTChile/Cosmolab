# `Docs/` — dossier maestro exportado

**Qué es:** `REGISTRO DE EXPERIMENTOS COSMOGÉNESIS` en `.docx` y `.pdf` (16-jul-2026) — una exportación
en formato documento (para lectura fuera del repo / compartir) del registro maestro del programa.

**Relación con `REGISTRO_EXPERIMENTOS_CS.md` (raíz):** ese `.md` es la fuente viva, versionada y
editable del registro secuencial (CS001, CS002, CS003… — la numeración única que reemplazó las
etiquetas internas dispersas CG001/CG002/R7a/r7b/etc., ver su §0). Los archivos de esta carpeta son
una fotografía exportada de ese registro (o de una versión previa) en formato portable. **Para el
estado más actual, usar el `.md` de la raíz; estos documentos pueden estar desactualizados** respecto
a experimentos corridos después del 16-jul (incluye todo el arco CS072/CS073 de esta última semana).
